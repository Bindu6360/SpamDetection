## 🚀 Quick Start (3 steps)

### 1️⃣ Install Dependencies
```bash

pip install -r requirements.txt
```

### 2️⃣ Train the Model
```bash

cd ..
```

### 3️⃣ Run the Application
```bash
python app.py
# Open browser to http://localhost:5000
```
